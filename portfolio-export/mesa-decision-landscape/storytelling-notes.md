# Storytelling notes

## Core narrative arc

1. **Problem.** A rehearsal produces a plan, a log, and a score that do not share a version. Missing evidence becomes a number. The published recap gets edited later.
2. **Insight.** The useful product is not a more vivid simulation. It is a gate: pin the definition, inspect citations, freeze the snapshot.
3. **Solution.** MESA is a local workspace. Scenario graph, facilitator control, findings review, and publication are one aggregate with command receipts.
4. **Execution.** TypeScript domain modules, HTML views in a React host, Node API, local Supabase, reviewed OpenAI proposals. Seventy registered screens, many of them honest "not connected" states.
5. **Outcome.** I can show a graph that does not fork the model, and a finding that cannot be approved because nothing was observed. I cannot show production users.
6. **Reflection.** Roughly a quarter to 30% of the lines are the reusable kernel. One scenario adapter is as large as that kernel. The gates hold inside a laptop boundary.

## Positioning

**Say this**

- Local prototype of a governed workflow.
- Graph is a projection. Dashed is not execution order.
- Accepted ≠ executed. Published ≠ editable.
- Not-observed is not zero. Small cohorts are suppressed.
- AI drafts narrative. A person accepts against a digest.
- I designed and built the harness. Single git author on the initial commit.

**Avoid this**

- Production platform, customers, or learning outcomes.
- "AI runs the exercise" or "automatic scoring."
- Cryptographic signatures, compliance certification, WCAG certification.
- A reusable percentage above ~30%.
- GLASSHOUSE as a secure facilitator vault.
- Revolutionary, seamless, game-changing, or magic.

## FAQ

**Is this in production?** No. Loopback, synthetic personas, docs say do not deploy.

**Did a model write the product?** I directed and authored the harness. The repo history is one commit under my name. I use reviewed model proposals inside the product; that is a feature with an accept button, not a claim about how the code was written.

**Can I click Generate and watch it write a scenario?** Only with a local `OPENAI_API_KEY`. Portfolio videos do not. The proof is the review gate, which works offline of the provider.

**Why is the UI not all React?** Strangler migration. Domain code stays testable from Node. Screen bodies are the remaining work. I say that before someone else finds `session-controller.ts`.

**Is the digest signed?** No. 32-bit FNV-style hash. It catches a stale form. It does not authenticate a publisher.

**Are the people real?** No. Fixture names in `src/fixtures.ts`.

**Can a consultant see Harbor?** Not in this harness. Consultant scope throws if the tenant is not Atlas.
